# Perlify · Portoviejo Challenge 2026

Material de presentación de Perlify para el Portoviejo Challenge 2026.

- `index.html`: diapositivas (15 láminas). Ábrelas en el navegador; se avanza con las flechas, la barra espaciadora o un clic, y con **F** se pone pantalla completa.
- `modelo-de-negocio.html`: el lienzo de modelo de negocio en tarjetas para imprimir en A4 y recortar. Al imprimir, activa "Gráficos de fondo".

La carpeta `img/` debe quedar junto a los HTML.
